## Currently Working On

Closing the gap between technically correct ML models and ones that work for real users — cleaner inputs, better UI, and models retrained on data that reflects current conditions rather than historical anomalies.

Open to collaborating on projects where the data problem is genuinely hard: messy, imbalanced, or high-stakes. Particularly interested in financial risk, NLP, and applied ML that ships to real users.
